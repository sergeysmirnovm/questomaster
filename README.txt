КВЕСТОМАСТЕР — Инструкция

1. Распакуйте архив в любую папку.
2. Откройте папку.
3. Запустите index.html в браузере (Chrome, Edge).
4. Чтобы добавить фото подарка — положите файл gift_location.jpg в эту папку.
5. Чтобы изменить загадки — отредактируйте assets/templates/animatronics.json.

Всё работает без интернета!
